# 🦖 Динозаврик

Набір браузерних ігор про динозаврика з Chrome: класичний раннер навпаки, 3D-версія, онлайн-гонка з друзями і власний чат ДіноКорд. Кожна гра це один HTML-файл без збірки і без сервера: відкрив у браузері, і можна грати.

**Грати онлайн:** https://dino-mu-seven.vercel.app

## Керування

| Дія | Клавіатура | Телефон / планшет |
|---|---|---|
| Стрибок | `Пробіл` або `↑` | тап по екрану або кнопка **▲ Стрибок** |
| Пригнутись | `↓` | кнопка **▼ Пригнутись** |
| Пауза | `P` | (у Реверсі й 3D) |
| Емодзі-реакція | `1` … `7` | кнопки під полем гри (в Онлайні) |

Тримай стрибок довше, щоб стрибнути вище. Якщо натиснути `↓` у повітрі, динозаврик швидше приземлиться.

## Динозаврик Онлайн

Відкрий https://dino-mu-seven.vercel.app/online.html

### Як грати з друзями

1. Введи нік і вибери колір.
2. Зайдіть в одну кімнату. За замовчуванням це `MAIN`. Кнопка **Нова** створює кімнату з випадковим кодом, який можна скинути другу. У списку **Відкриті кімнати** видно, де зараз хтось грає.
3. Вибери **режим гонки** і натисни **▶ Старт гонки**. Після відліку 3-2-1 усі в кімнаті біжать одночасно.
4. Траса однакова для всіх: кактуси, птерозаври і бонуси стоять на тих самих місцях. Хто впаде останнім, той переміг 🏆.

### Що є в грі

- **Режими:** Звичайний, Швидкий (старт на великій швидкості), Переворот (світ перевертається кожні 300 очок).
- **Бонуси:** 🛡 щит рятує від одного удару, ×2 дає подвійний стрибок на 10 секунд.
- **Чат кімнати** з повідомленнями про те, хто зайшов, вийшов чи переміг.
- **Емодзі-реакції** 👍 😂 😮 😡 🔥 🦖 👋 злітають над твоїм динозавриком у всіх на екрані.
- **Голосовий чат:** кнопка **🎤 Голосовий чат** під полем гри. Браузер попросить дозвіл на мікрофон. **🎙 Вимкнути мік** глушить тебе, але ти й далі чуєш інших. У списку гравців видно 🎤 (у голосі), 🔊 (говорить) і 🔇 (мікрофон вимкнено).
- **Твоя статистика:** забіги, перемоги, рекорд, зібрані бонуси. Зберігається в цьому браузері.

### Як це працює

- **Кімнати й гонка** синхронізуються через публічний MQTT-брокер `broker.emqx.io` по WebSocket. Тому гра працює в будь-якій мережі: Wi-Fi, мобільний інтернет, різні міста.
- **Траса** генерується з одного випадкового числа (seed), яке передається разом зі стартом. Кожен гравець рахує світ у себе, а по мережі летять лише позиція, стан і рахунок.
- **Голос** іде напряму між гравцями через WebRTC ([PeerJS](https://peerjs.com/)). Сервер PeerJS лише допомагає гравцям знайти одне одного.
- Якщо гру відкрито як артефакт на claude.ai, замість MQTT використовуються вбудовані кімнати claude.ai. Голосового чату там немає, бо мікрофон і WebRTC заблоковані.

## ДіноКорд

Відкрий https://dino-mu-seven.vercel.app/discord.html

Створи сервер і скинь друзям код або введи код друга. Тут є канали, особисті повідомлення, голосові дзвінки, трансляція камери і показ екрана, правила сервера, закріплені повідомлення і рейтинг. Динозаврика можна запустити просто в ДіноКорді: біля твого імені з'явиться «грає», а рекорди потраплять у рейтинг сервера.

## Запуск у себе

Нічого встановлювати не треба:

```bash
git clone https://github.com/lozinmatvii-hub/Dinosaur-.git
cd Dinosaur-
python3 -m http.server 8000
```

Потім відкрий http://localhost:8000. Реверс і 3D працюють і просто подвійним кліком по файлу. Для Онлайну й ДіноКорду краще запускати через локальний сервер, бо браузер не дає мікрофон сторінкам, відкритим як файл.

## Публікація

Сайт публікується на [Vercel](https://vercel.com) прямо з цього репозиторію: кожен коміт у `main` за хвилину-дві з'являється на https://dino-mu-seven.vercel.app. `index.html` стає головною сторінкою, а інші файли доступні за своїми назвами, наприклад `/online.html`.

## Обмеження

- **Голос** іде напряму між пристроями. У деяких мобільних мережах пряме з'єднання не встановлюється, і тоді голос може не працювати, хоча сама гра працюватиме. Голосовий чат розрахований приблизно на 6-8 людей у кімнаті.
- **Публічні сервери** (`broker.emqx.io`, `0.peerjs.com`) безкоштовні й спільні для всіх. Коди кімнат не секретні: якщо хтось введе той самий код, він потрапить у вашу кімнату. Для приватної гри бери довгий випадковий код кнопкою **Нова**.
- **Рекорди, скіни, монети й статистика** зберігаються в браузері (localStorage). На іншому пристрої або після очищення даних сайту вони почнуться з нуля.

## Технології

Чистий HTML, CSS і JavaScript, без фреймворків і збірки. Графіка на Canvas 2D (піксель-арт задано рядками прямо в коді), 3D на [three.js](https://threejs.org/), звуки генерує Web Audio API. Шрифти [Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans) і [Rubik](https://fonts.google.com/specimen/Rubik).
